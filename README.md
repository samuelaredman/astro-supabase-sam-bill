# Chekpoint

Community game reviews. Score, write, and share your takes on the games you've played.

**Live at [chekpoint.gg](https://chekpoint.gg)**

---

## Stack

- [Astro 5](https://astro.build) — SSR via Netlify adapter
- [Supabase](https://supabase.com) — Postgres, Auth, Storage
- [Tailwind CSS v4](https://tailwindcss.com)
- TypeScript

## Development

```bash
npm install
npm run dev       # localhost:4321
npm run build     # type-check + build
npm test          # unit tests
```

Requires a `.env` file — see `.env-example` for required variables.
